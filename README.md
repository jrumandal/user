# @mf/user — User Micro-Frontend (Vue 3)

The **user** micro-frontend (MF) is a **source-only ESM package** that renders a
signed-in profile (name, email, address) or a sign-in form, as a web component
(`<mf-user>`). It is consumed by the **shell** (and the mobile wrapper), which
bundles it with Vite.

> This is a faithful port of the reference `libs/mf/user` from the
> `microfrontend` monorepo, split into its own independently versioned repository.
> **Styling:** **Tailwind v4** utility classes driven by the `@jrumandal/design-tokens` design system (CSS variables), generated by the shell (the Tailwind v4 host).

## Stack

- **Vue 3.5** (Composition API, `createApp` / `renderToString`)
- **TypeScript 5.9** (strict, `noEmit`)
- **Vitest 3** + **jsdom** (unit tests)
- **ESLint 9** (flat config, `typescript-eslint`)
- **Node 22 LTS** (`.nvmrc`)

## Shared dependencies

| Package | Purpose |
| --- | --- |
| `@jrumandal/contracts` | Domain types (`User`, `Address`, `LoginInput`, `UpdateProfileInput`) + `MfApolloClient` |
| `@jrumandal/design-tokens` | Design tokens (`Tokens`, `cssVar`) — Tailwind v4 / CSS variables |
| `@jrumandal/event-bus` | Typed cross-MF event bus (`EventBus`, `MFEventMap`) |

## Public API

```ts
import {
  UserPanel,          // Vue component
  UserPanelProps,     // props type
  formatAddress,      // address -> display string
  UserElement,        // <mf-user> custom element
  render,             // SSR: render(props) -> Promise<string>
  register,           // register the <mf-user> custom element (idempotent)
  USER_ELEMENT_TAG,   // 'mf-user'
  hydrate,            // hydrate existing <mf-user> elements
} from '@mf/user';
```

### Web component

```html
<mf-user data-user='{"id":"u-1","email":"jane@example.com","name":"Jane Doe","address":{...}}'></mf-user>
```

## Development

```bash
pnpm install
pnpm lint
pnpm typecheck
pnpm test
pnpm build   # no-op (source-only)
```

## Publishing

`pnpm publish` bumps the patch version and publishes to the configured registry
(GitHub Packages by default). See `scripts/publish.mjs`.
